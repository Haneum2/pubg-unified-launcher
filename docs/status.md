# 구현 상태 (2026-10-25)

PRD 4장 기능 요구사항 기준. "확인" 열은 실제로 무엇까지 확인했는지 적었고, 확인하지 못한 것은 **미확인**으로 표시했다.

| ID | 기능 | 우선순위 | 상태 | 확인 |
| --- | --- | --- | --- | --- |
| F1 | 설치 감지 | P0 | 구현됨 | 이 PC에서 레지스트리로 Steam 경로와 `libraryfolders.vdf`의 PUBG 설치를 탐지함을 확인. 미설치·수동 경로 우선순위는 단위 테스트로 확인. "Steam 폴더 선택" 대화상자로 직접 골라 보는 것은 **미확인** |
| F2 | 서버 선택·실행 | P0 | 구현됨 | 탭 전환, Steam 미설치 시 실행 차단(단위 테스트), 게임 실행 중 재실행 차단(실제 앱)을 확인. **런처로 실제 PUBG를 Steam에서 시작하는 것은 미확인**, **카카오 탭에서 공식 사이트가 브라우저로 열리는 것도 미확인** |
| F3 | 마지막 선택 기억 | P0 | 구현됨 | 실제 앱에서 탭을 바꾸면 `settings.json`의 `lastServer`가 저장됨을 확인. 저장된 값을 다시 읽는 것은 단위 테스트로 확인. 카카오를 고른 뒤 재시작했을 때 카카오 탭이 선택되어 있는지는 **미확인** |
| F4 | 실행 상태 표시 | P0 | 구현됨 | 실제로 떠 있던 `TslGame.exe`를 "게임 실행 중"으로 표시함을 확인. 30초 타임아웃과 실패 원인 문구는 단위 테스트로만 확인(**실제 실패 상황은 미확인**). 카카오 게임 프로세스 이름이 `TslGame.exe`인지 **미확인** |
| F5 | 실행 옵션 프로필 | P1 | 구현됨 | 잘못된 값 저장 시 오류 표시, 올바른 값 저장을 실제 앱에서 확인. 검증 규칙은 단위 테스트. **Steam 인자가 실제 게임에 전달되는지, 실행 전·후 프로그램이 실제로 실행되는지, 프로그램 저장 확인 창은 미확인** |
| F6 | 점검·패치 정보 | P1 | 부분 구현 | Steam: 공식 뉴스 API로 최근 패치 제목 표시를 실제 앱에서 확인("Patch Notes - Update 43.2"), 네트워크 실패 처리는 단위 테스트. 점검은 공식 일정 데이터가 없어 "최근 48시간 내 점검 제목 공지"로 추정만 하고, **실제 점검 공지로는 미확인**. 카카오는 공식 데이터 경로가 없어 공지 링크로 대체(**링크 열기는 미확인**) |
| F7 | 플레이 기록 | P1 | 구현됨 | 게임 감지 시 마지막 실행 시각이 기록됨을 실제 앱에서 확인. 누적 시간 계산은 단위 테스트로 확인. **실제 장시간 플레이 후 누적 시간은 미확인** |
| F8 | 바로가기 | P2 | 구현됨 | 설치본(`win-unpacked`)에서 바탕화면 바로가기 2개 생성과 대상·인자(`--server=steam/kakao`)를 확인하고 지움. 창 없이 실행하다 실패하면 오류 창이 뜨는 것, 런처를 두 번 켜도 하나만 뜨는 것을 확인. **바로가기로 실제 게임을 시작하는 것은 미확인** |
| F9 | 자동 업데이트 | P2 | 부분 구현 | electron-updater 연동, 허락 후 다운로드·설치 흐름 구현. 설치본에서 확인 실패 시 "업데이트 정보를 가져올 수 없음"으로 표시되고 앱이 멈추지 않음을 확인. **GitHub 저장소가 자리 표시값(`CHANGE_ME_GITHUB_OWNER`)이라 실제 업데이트는 동작하지 않으며 전체 흐름은 미확인** |

## PRD 시나리오·비기능 요구 중 남은 것

| 항목 | 상태 |
| --- | --- |
| 시나리오 4 "점검일: 시작 버튼 대신 점검 안내, 다른 서버로 전환 제안" | 부분 구현: 점검 정보가 틀릴 수 있어 시작 버튼은 막지 않고 옆에 안내만 표시(2단계 지시). 다른 서버로 전환 제안은 미구현 |
| 시나리오 5 실패 원인 "미로그인" | 부분 구현: 런처는 로그인 상태를 알 수 없어 30초 타임아웃 문구에서 "Steam 로그인 상태를 확인하세요"로만 안내 |
| 안정성: 런처 종료 후에도 게임 계속 실행 | 구조상 보장(게임은 Steam/카카오가 띄움). 실제 확인은 **미확인**, README에 수동 테스트 절차 있음 |
| 성능: 런처 시작 3초 이내, 낮은 대기 메모리 | **미측정** |
| 호환성: Windows 10 64비트 | Windows 11에서만 실행. Windows 10은 **미확인** |
| 실행 성공률·첫 설정 시간 등 지표 | 측정 기능 없음(익명 사용 로그는 동의 절차가 필요해 만들지 않음) |
| 설치 파일 | `npm run dist`로 `release\pubg-unified-launcher-setup-1.0.0.exe` 생성 확인. 코드 서명 없음. **설치 파일로 실제 설치·제거는 미확인** |

## 안전 점검 결과 (3단계)

전체 소스(`src/`)를 검색해 확인했다.

| 항목 | 결과 |
| --- | --- |
| 게임 프로세스 메모리 읽기/쓰기, DLL 주입, 게임 파일 수정 | 없음. 게임 쪽은 `tasklist` 프로세스 목록 조회만 함. 파일 쓰기는 런처 자신의 `settings.json`, `records.json`(`%APPDATA%\pubg-unified-launcher`)뿐. 네이티브 모듈 없음 |
| 아이디·비밀번호·토큰 저장, 로그인 자동 입력 | 없음. "로그인"은 안내 문구에만 등장. 웹 페이지 조작(`executeJavaScript` 등)이나 입력 자동화 없음 |
| 사용자 동의 없는 외부 데이터 전송 | 사용자 데이터 전송 없음. 외부 요청은 Steam 뉴스 API(앱 ID만), GitHub 업데이트 확인(설치본만) 두 가지이고 README "외부 통신"에 공개함. 둘 다 시작할 때 자동으로 요청하므로, 그것도 동의를 받아야 한다면 설정 옵션 추가가 필요 |
| 실제 상표·로고 이미지 사용 | 없음. 이미지 파일·CSS 이미지 없음. 앱 아이콘은 Electron 기본 아이콘. 이름에 "PUBG", "Steam", "카카오" 문자열만 사용하고 하단에 비공식 문구 표시 |
